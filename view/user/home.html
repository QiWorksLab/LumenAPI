BEFORE YOU CONNECT / 接入前了解

常见问题

如何调用接口？

创建账号后进入用户中心，创建 API Key，再从接口目录打开文档。文档提供简单调用与高级 cURL 示例，请按参数表填写必填项。

额度什么时候扣除？

按接口配置的成功规则判定后扣除相应额度，失败请求不扣额度。每个接口的单价会在目录与文档中展示。

可以给不同机器人分配密钥吗？

可以。为不同应用创建独立 API Key，按需暂停或吊销；同一用户的密钥共用账户额度。

充值和退款在哪里操作？

登录后进入“充值与退款”。可退款金额按未使用的付费额度计算，赠送额度不折算现金，具体以订单可退款信息为准。

准备好开始连接了吗？

创建账号，为你的应用配置第一个 API Key。
