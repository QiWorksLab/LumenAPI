高级参数定义

定义调用者可以传入的参数。Query 会自动拼到上游 URL；Header 会转发为请求头；Body 会组装 JSON；Path 可替换上游 URL 中的 {参数名}。

{volist name="params" id="p"}{/volist}
参数名位置类型必填默认值说明

在线测试

只测试当前已保存的上游地址；遵循 SSRF、防重定向、端口和 1MB 响应限制。测试不会扣用户额度。

调用方式
浏览器友好地址：
http://apil.qiqi520.cn/v1/{$item.slug}?key=你的Key&参数=值
标准方式也可使用 Authorization: Bearer 你的Key。简单透传模式会自动转发除 key 外的 Query 参数。
{$item.method} http://apil.qiqi520.cn/v1/gateway/{$item.slug}
请求头需携带 Authorization: Bearer <LumenAPI Key>。Query 参数直接跟在调用地址后，例如 ?url=...。
